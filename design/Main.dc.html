시맨틱 구조 — 화면 요소를 어떤 태그로 만드는가

header / nav

앱바, 카테고리 칩, 바텀 탭바, 페이지네이션, 브레드크럼. 각각 aria-label로 구분하고 현재 위치는 aria-current.

section / article

섹션은 aria-labelledby로 제목과 연결. 상품 카드·리뷰·주문 건은 각각 article.

button / a

동작은 button, 이동은 a. 아이콘 전용 버튼엔 반드시 aria-label. 사이즈·결제수단은 role="radio".

dl / table

결제 금액 내역은 dl, 상품 고시정보·어드민 목록은 table + caption + th scope.

폼 에러는 시각적으로만 표시하지 않고 프로그래밍적으로 연결합니다

<label for="tel">연락처</label>
<input id="tel" aria-invalid="true" aria-describedby="tel-err" />

앱 셸

Capacitor 웹뷰에서는 OS 상태바와 홈 인디케이터가 레이아웃 위에 그려집니다. 고정 헤더는 padding-top: env(safe-area-inset-top), 하단 탭바와 고정 CTA는 padding-bottom: env(safe-area-inset-bottom)를 더해야 잘리지 않습니다. 이 시안의 모바일 화면은 상태바를 그리지 않았습니다 — 실제 기기에서 OS가 그 자리를 차지하기 때문입니다.
