# 돌연변이 목록

`pnpm mutate <묶음 뿌리> <이 폴더의 파일> <검사 파일...>` 로 쓴다.
한 덩이를 판별할 때 쓰고 **커밋에는 남기지 않는다** — 소스가 바뀌면 `from` 이
안 맞아 그대로 썩는다. 판별한 결과(몇 개가 지는지)는 커밋 메시지에 적는다.

모양:

```json
[
  {
    "name": "사람이 읽는 이름 — 무엇을 망가뜨렸는가",
    "file": "src/lib/foo.ts",
    "from": "정확히 한 번 나오는 글자",
    "to": "바꿔 넣을 글자"
  }
]
```

`from` 은 **들여쓰기까지 정확해야** 한다. 어긋나면 치환이 헛돌고, 도구는 그것을
"바꿀 자리를 0번 찾았다" 로 알려 준다 — "살아남았다" 와 혼동하지 않게.
